# README artwork

The editable 1400 × 560 SVG cover uses forest green `#24483e` for the background, white `#ffffff` for primary text, pale sage `#cad7c4` for secondary text, and lemon yellow `#f4ce14` for the fruit and accent. Georgia carries the title; Arial/Helvetica carries supporting text. The receipt and lemon are original decorative vector artwork, not a measured chart or screenshot. No report values are embedded in the cover.

Section icons use the workspace's canonical 24 × 24 geometry with 1.6-unit rounded yellow strokes on a forest-green backing. They are decorative beside descriptive text headings and remain legible on light and dark GitHub themes. All assets are local and have no external font or image dependency.
